# VietLabor AI UI Design System

A modern, accessible interface inspired by high-end legal publishing and modern conversational AI.

## Color Palette
- Primary Red: `#a5121b` (Crimson Gold national crest theme)
- Accent Gold: `#c59b27`
- Background Canvas: `#fbf8f2` (Warm parchment)
- Surface Card: `#ffffff`
- Text Primary: `#1f1a17`
- Border Line: `#e8dac8`

## Navigation Model
- ChatGPT-style collapsible left sidebar with quick "Cuộc trò chuyện mới".
- Instant 0ms view pane switching for secondary resources (Biểu mẫu, Văn bản, Tình huống, FAQ).
