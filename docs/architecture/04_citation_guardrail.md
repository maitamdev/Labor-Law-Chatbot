# Citation Guardrail & Material Premise Gate

To ensure legal accuracy and eliminate hallucination, VietLabor AI enforces strict grounding rules:

1. **Official Source Restriction**: Citations must link exclusively to verified official portals (congbao.chinhphu.vn, thuvienphapluat.vn).
2. **Material Premise Check**: If user questions lack crucial facts (e.g., contract type, company seniority), the system explicitly flags unresolved issues instead of guessing.
3. **Evidence Completeness Metric**: Output is blocked if evidence coverage ratio falls below 1.0 for decisive statutory claims.
